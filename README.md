# 1. Composite Fabrication

## Objective

To gain hands-on experience in fabricating composite UAV structures
using carbon-fiber and glass-fiber reinforcements over XPS-based
geometries.

## Work Performed

- Studied conventional hand lay-up techniques for composite fabrication.
- Fabricated composite specimens using carbon-fiber and glass-fiber
  reinforcement with epoxy resin.
- Worked with XPS-based UAV geometries and specimens.
- Studied fiber layering and laminate preparation.
- Implemented vacuum bagging for improved consolidation and surface finish.
- Fabricated multiple specimens while progressively improving the
  fabrication process.

## Process

1. Preparation of the XPS-based specimen/mould
2. Surface preparation
3. Fiber cutting and lay-up
4. Epoxy resin application
5. Vacuum-bagging setup
6. Vacuum consolidation
7. Curing
8. Demoulding and inspection

# 2. UAV Propulsion-System Testing

## Objective

To experimentally characterize UAV propulsion systems using an
instrumented thrust test bed.

## Parameters Measured

- Thrust
- RPM
- Current
- Voltage
- Voltage drop
- Power
- Temperature
- Vibration

Experimental readings were collected during extended-duration
motor and propeller testing using an Arduino-based data acquisition
setup.

## Data Analysis

The acquired data was processed and analyzed using MATLAB to generate
performance curves and identify trends in propulsion-system behavior.

Additional frequency and noise analysis was performed using
Audacity from recorded motor-propeller acoustic data.

### Analysis

- Thrust vs. Voltage
- Current vs. Voltage
- Frequency vs. Noise
- Motor/propeller performance trends
- Temperature and endurance observations
