# Propulsion System Testing

## Overview

Experimental evaluation of UAV propulsion systems involving motors,
propellers, and electronic speed controllers (ESCs) using an
instrumented thrust test bed.

The testing focused on measuring propulsion-system performance under
extended-duration operating conditions and acquiring experimental
data for subsequent analysis.

---

## Test Setup

The propulsion system was evaluated using a dedicated test bed with
Arduino-based data acquisition and serial monitoring.

The test setup involved:

- UAV motor
- Propeller
- Electronic Speed Controller (ESC)
- Thrust measurement system
- Current and voltage measurement
- Temperature monitoring
- RPM measurement
- Arduino-based data acquisition

---

## Parameters Measured

The propulsion-system tests were used to monitor and record:

| Parameter | Purpose |
|---|---|
| Thrust | Evaluate propulsive force |
| Current | Monitor electrical current draw |
| Voltage | Monitor supply voltage and voltage drop |
| RPM | Evaluate rotational speed |
| Temperature | Monitor thermal behaviour |
| Power | Evaluate electrical power consumption |

---

## Experimental Procedure

The propulsion system was operated on the test bed while the
experimental parameters were monitored through the Arduino serial
interface.

Testing was conducted over extended-duration runs, with real-time
measurements recorded for subsequent processing and analysis.

The acquired data was organized and analysed using MATLAB and
Microsoft Excel.

---

## Data Analysis

MATLAB was used to process and visualize the experimental data.

The analysis included:

- Thrust variation with operating conditions
- Current and voltage behaviour
- RPM monitoring
- Temperature variation during operation
- Electrical power analysis
- Experimental data visualization

The measured parameters were examined to understand the operating
characteristics and performance of the tested motor-propeller system.

---

## Frequency and Noise Analysis

In addition to propulsion-performance measurements, frequency versus
noise behaviour was investigated.

Audio recordings from the motor-propeller system were analysed using
Audacity to generate frequency-domain spectrographs.

The frequency/noise analysis was used to examine the acoustic
characteristics associated with motor-propeller operation.
